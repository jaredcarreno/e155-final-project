# e155-final-project
E155 Final Project - Autotune created by Jared Carreno, Emma Angel and Shreya Jampana. The main parts of this project consist of the MCU sampling and signal processing which can be found in the mcu folder and the FGPA FFT which can be found in the FPGA folder. The FPGA folder contains the radiant project for the code, quarta simulation files, and the source code for 512-point FFT and the testbenches. The MCU folder contains all of the libraries needed for the code in the lib folder with the new ones being ADC, DMA and external DAC. The main file can be found in the src folder.
